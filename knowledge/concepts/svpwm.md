# SVPWM(空间矢量脉宽调制)

## 基本原理

将三相逆变器8个开关状态对应的电压空间矢量，通过相邻两个有效矢量和零矢量的时间分配，合成任意方向的参考电压矢量。

## 六扇区划分

```
        β轴
        |
   S2   |   S1
  V3(010)|V2(110)
        |
--------+--------α轴
  V4(011)|V1(100)
   S3   |   S0
```

8个基本矢量: V0(000), V1(100), V2(110), V3(010), V4(011), V5(001), V6(101), V7(111)

## 作用时间计算

给定参考电压 Vref = vα + j·vβ:

1. 计算参考矢量幅值和角度
2. 判断所在扇区(1-6)
3. 计算相邻两个有效矢量的作用时间 T1, T2
4. 零矢量时间 T0 = Ts - T1 - T2 (Ts为开关周期)

## 典型参数

- 开关频率: 10kHz (Ts = 100μs)
- 死区时间: 2-5μs
- 直流母线电压: 根据电机额定电压确定
